## 建议的整理方式

可以按方向或主题逐步扩展，例如：

```text
CTF/
├── README.md
├── Web00.md
├── Web/
│   ├── README.md
│   ├── SQL-Injection.md
│   └── XSS.md
├── Misc/
│   └── README.md
└── images/
```

不用提前建好全部目录。遇到新主题时再创建对应文件夹即可，自动生成脚本会扫描多级目录。

请只在自己拥有权限的靶场、练习环境或明确授权的目标中开展安全测试。
