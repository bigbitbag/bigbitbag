### 工程必读与查阅资料

| 编号 | 官方资料                                                     | 只读这些部分                                                 |
| ---- | ------------------------------------------------------------ | ------------------------------------------------------------ |
| P1   | [Python：函数](https://docs.python.org/3/tutorial/controlflow.html#defining-functions) | 定义、参数、返回值、文档字符串；暂不钻全部高级参数形式       |
| P2   | [Python：数据结构](https://docs.python.org/3/tutorial/datastructures.html) | 列表、字典、集合、循环；与统计任务结合                       |
| P3   | [Python：文件读写](https://docs.python.org/3/tutorial/inputoutput.html#reading-and-writing-files) | with、文本、编码、读写模式；JSON 小节按输出需要查            |
| P4   | [Python：错误与异常](https://docs.python.org/3/tutorial/errors.html) | 读异常、捕获、抛出与清理；不使用裸 except 吞掉全部错误       |
| P5   | [Python：模块](https://docs.python.org/3/tutorial/modules.html) | 导入、脚本入口、搜索路径、包的基础                           |
| P6   | [Python：虚拟环境与包](https://docs.python.org/3/tutorial/venv.html) | 创建/使用环境、pip、依赖记录；沿用能解释清楚的已有环境也可以 |
| P7   | [Python：csv](https://docs.python.org/3/library/csv.html)    | DictReader/DictWriter 与文件打开方式；与 Pandas 方案二选一，不重复重写整个项目 |
| P8   | [Python：pathlib](https://docs.python.org/3/library/pathlib.html) | Path、相对/绝对路径、读取/写入及目录操作对应示例             |
| P9   | [Python：Logging HOWTO](https://docs.python.org/3/howto/logging.html) | 基础等级、配置、异常记录；先用简单日志                       |
| P10  | [Python：argparse](https://docs.python.org/3/library/argparse.html) | Tutorial、位置参数、可选参数、帮助信息和解析入口             |
| T1   | [pytest：入门](https://docs.pytest.org/en/stable/getting-started.html) | 第一条测试、assert、异常测试、运行与读取失败报告             |
| T2   | [pytest：临时文件](https://docs.pytest.org/en/stable/how-to/tmp_path.html) | tmp_path 的基本例子，为文件读写测试隔离样例                  |
| N1   | [NumPy：初学者基础](https://numpy.org/doc/stable/user/absolute_beginners.html) | array、shape、dtype、索引/切片、基本运算与广播、reshape；其他部分按需 |
| D1   | [Pandas：入门教程](https://pandas.pydata.org/docs/getting_started/intro_tutorials/index.html) | 读写表格、选择子集、生成新列、统计汇总；本月不通读全部       |
| K1   | [sklearn：LinearRegression](https://scikit-learn.org/stable/modules/generated/sklearn.linear_model.LinearRegression.html) | fit/predict、输入 shape、基本示例；不钻全部参数              |
| K2   | [sklearn：常见陷阱](https://scikit-learn.org/stable/common_pitfalls.html) | 预处理一致性与数据泄漏；第 4 周必读对应小节                  |
